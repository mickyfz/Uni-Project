# University Project - Student & Teacher Exam System

A simple Django university project for semester exams (Midterm & Final).

### Features:
1. **Student:**
   - Login / Register as Student.
   - Answer Quiz for Midterm and Final.
   - Upload Video for Viva (Midterm & Final).
   - View Marks.

2. **Teacher:**
   - Login as Teacher.
   - Add Course, Quiz, and Viva (Midterm / Final).
   - Check Quiz answers and give marks.
   - Watch Student Viva Video and give marks.
   - View Student Marksheet table.

---

### How to Run:
1. Double click `run_server.bat` OR run:
```powershell
cd "D:\Uni Project"
.\venv\Scripts\activate
python manage.py runserver
```
2. Open browser at: **http://127.0.0.1:8000/**
